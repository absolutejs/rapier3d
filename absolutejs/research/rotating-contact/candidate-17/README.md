# Rejected candidate 17: current lever-arm linearization

The stored fixed-normal constraint tracks rotated local anchors while its prepared angular Jacobians use the original lever arms. This experiment re-differentiates that same constraint at current poses: J_omega1 = (R1*a1) cross n, J_omega2 = (R2*a2) cross -n, with corresponding inverse-inertia products and effective mass. It applies only to active single-point, zero-friction rows in the biased update and post-integration relax update. It does not transport normals, change inertia policy, change friction frames, or refresh multi-point block coupling. Both Coulomb and twist builders are covered.

The experiment compiles and retains the research suite outcome of 21 pass / four upstream-motion parity failures (48,827 assertions). The 60-case independent rotating-support probe passes its static, native-query-oracle and prescribed-path controls, but physical overlap does not generally improve. Broad-face 960Hz/6rad/s depth changes from 0.4161mm to 0.4197mm; 240Hz/30rad/s worsens from 82.58mm to 87.21mm. One severe 60Hz/30rad/s case improves from 98.18mm to 75.59mm, which is insufficient and still unacceptable. Full cases, trajectories and native provenance are retained.

Reject as a physical fix. A current-arm Jacobian by itself does not resolve the rotating-support problem. The branch will restore candidate-16 solver source and native bytes while retaining this experiment's commit and evidence. No production solver change or npm release is authorized by these results. Next work must treat normal/feature evolution and all affected constraint quantities consistently; do not repeat this isolated arm-only change as though it were untested.
